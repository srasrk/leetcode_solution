You are given an array of integers nums and an integer target, return indices of the two numbers such that they add up to target.

You may assume that each input would have exactly one solution, and you may not use the same element twice.

You can return the answer in any order.

 

Example 1:

Input: nums = [2,7,11,15], target = 9
Output: [0,1]
Explanation: Because nums[0] + nums[1] == 9, we return [0, 1].

Example 2:

Input: nums = [3,2,4], target = 6
Output: [1,2]

Example 3:

Input: nums = [3,3], target = 6
Output: [0,1]

 

Constraints:

1. 2 <= nums.length <= 10^4
   - nums.length means the number of elements in the array.
   - 10^4 = 10,000
   - So, nums can contain between 2 and 10,000 elements.

2. -10^9 <= nums[i] <= 10^9
   - nums[i] means each element of the array.
   - 10^9 = 1,000,000,000
   - Each number can be from -1,000,000,000 to +1,000,000,000.

3. -10^9 <= target <= 10^9
   - target can also be from -1,000,000,000 to +1,000,000,000.

4. Only one valid answer exists.
   - There is exactly one pair of numbers whose sum equals target.

 
Follow-up: Can you come up with an algorithm that is less than O(n2) time complexity?
